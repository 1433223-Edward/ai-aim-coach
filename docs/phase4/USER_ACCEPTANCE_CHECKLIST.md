# Phase 4 最终人工验收

入口：<http://127.0.0.1:8012/#/hub>。使用HTTP，先刷新页面。服务为本地Demo；真实模型调用由你主动决定，测试报告没有将Fake结果当作真实模型。

## A. 首次与自由训练

- [ ] Hub可见六个场景，按Clicking / Switching / Tracking分组；无历史的任务显示空状态。
- [ ] 如果旧活动实验或冻结尺寸不匹配，先在Hub点“结束当前实验（保留历史）”，确认历史仍在。
- [ ] 打开Settings，检查Controls / Appearance / Experiment三组、范围、间距、键盘焦点、独立滚动。
- [ ] 改准心/目标颜色并保存；创建一个新的自由场景实验，确认新偏好生效。活动实验的配置不应被后续修改覆盖。
- [ ] 自由参数设5或6目标、足够时长，从卡片进入Arena；READY应显示正确任务/难度/数量或时长。
- [ ] 桌面1366×768、1440×900、1920×1080分别检查ACTIVE没有页面纵向滚动，目标与HUD不重叠。
- [ ] 点击训练：故意MISS一次再完成；跟随训练：移动指针，观察水平/垂直反射和Reactive变化。
- [ ] 结束后等待数据库确认，再看Summary核心指标、条件版本、历史对比；ACTIVE不应出现Summary或AI图表。

## B. 暂停、退出与恢复（重点补充人工检查）

- [ ] P / Esc进入暂停；等几秒，计时不应继续减少、跟随采样不应增加；恢复后继续计时。
- [ ] 暂停时Settings可开，ACTIVE不可开；Drawer滚动不改变训练区位置与尺寸。
- [ ] 点退出，应出现页面内统一确认框；取消应保持暂停，不丢证据；确认后归档为未完成，不能推进为有效完成。
- [ ] 切换应用/最小化/切换标签验证真实失焦暂停；回到页面不应自动继续。
- [ ] ACTIVE改变窗口尺寸，确认归档未完成，而非混合两套坐标系。
- [ ] ACTIVE刷新，确认退出记录进入待上传恢复；重试保留原SessionID，不重复写入。
- [ ] 临时断开测试服务后结束训练，应显示未确认并可导出；恢复服务并重试，只保存一份。
- [ ] 小于620px的窄窗口检查合理降级、按钮可达；本轮未完成窄屏浏览器实测，不应以桌面结果代替。

## C. 历史与分析

- [ ] Summary → History，能读到实际Experiment / Session和详情；刷新后记录仍存在。
- [ ] 改场景/日期/ExperimentID过滤；图表只显示相同查询身份范围。
- [ ] 切换对比条件，检查difficulty、版本、seed、控制参数、viewport标签，不可比记录不混排。
- [ ] 静态任务显示Accuracy /命中耗时/TPS；跟随显示Coverage/Error；不存在的指标不补假数。
- [ ] 单点说明样本不足；无记录显示Empty State；接口失败清除旧图表并提示重试。

## D. AI计划与旧功能

- [ ] AI Coach中查看模型来源、真实SessionIDs和推荐限制；无Key应报错，不自动给出Fake计划。
- [ ] 在你同意使用模型账号额度的前提下请求计划；可拒绝或重新生成，旧计划保留。
- [ ] 接受后只创建实验，Arena保持READY；手动完成各Session，确认仍属同一TrainingPlan。
- [ ] Coach完成率正确；缺少3条基线/2条执行数据时，改善应为待验证，不声称因果提升。
- [ ] 计划完成后再次练习应明确是独立自由训练，不能假装计入已完成计划。
- [ ] Original Flick在支持Pointer Lock的Chrome/Edge测试；旧设置、保存、历史分析及兼容Insights仍可用。

## 推荐5分钟演示

Hub介绍任务与同条件摘要 → 选择Flick 5目标 → Arena展示专注布局 → P暂停展示Settings → 恢复完成 → Summary与History真实数据 → Coach展示已有计划或无Key边界 → 说明基线/因果限制。

优先反馈：退出弹窗、真实失焦、窄屏、原Flick硬件输入、真实模型。这些项目在报告中明确保留人工验收状态。
